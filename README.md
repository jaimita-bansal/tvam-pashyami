# TvamPashyami AI

Landing page for [TvamPashyami AI](https://tvampashyami.com).

## Deploy with git

```bash
cd ~/Documents/tvam-pashyami
bash deploy-github-pages.sh
```

Then create the repo on [github.com/new](https://github.com/new) (name: `tvampashyami`), push, and enable **Settings → Pages → main / root**.

Custom domain: `tvampashyami.com` (see `CNAME` file).
